# Portfolio 3D

My previous portfolio: a Next.js site with an interactive 3D scene, smooth scrolling and a custom cursor.

**Live:** https://portfolio-mu-nine-25.vercel.app

## Stack

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Three.js with React Three Fiber and drei, GSAP, Framer Motion and Lenis.

## Structure

```
app/           pages: home, about, projects, contact
components/    Scene3D, CustomCursor, SmoothScroll, Navigation, TopLoader
lib/projects.ts project data
```

## Run

```bash
npm install
npm run dev
```
